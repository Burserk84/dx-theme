# ساعت و بازار | New Tab

اکستنشن کروم برای جایگزینی تب جدید با یک پنل شیشه‌ای شامل:

- **ساعت و تاریخ** — ساعت محلی لپ‌تاپ (فرمت ۱۲/۲۴ قابل تغییر با کلیک روی دکمه کنار ساعت) + تاریخ کامل شمسی و میلادی
- **لینک‌های من** — دو ردیف میانبر قابل افزودن/حذف (دکمه «ویرایش» برای نمایش ضربدر حذف)
- **قیمت لحظه‌ای** — دلار، تتر، طلای ۱۸ عیار، سکه امامی و نیم‌سکه از TGJU (هر ۵ دقیقه خودکار به‌روز می‌شه)
- **والپیپر** — آپلود عکس یا ویدیوی MP4 (با کشیدن و رها کردن فایل هم کار می‌کنه) + تنظیمات شفافیت و بلور شیشه

## نصب در کروم

1. فایل `chrome-theme.zip` رو باز (extract) کن — یا خود پوشه `chrome-theme` رو داشته باش
2. برو به آدرس `chrome://extensions`
3. گوشه بالا-راست **Developer mode** رو روشن کن
4. روی **Load unpacked** کلیک کن و پوشه `chrome-theme` رو انتخاب کن
5. یه تب جدید باز کن ✨

## نکته‌ها

- قیمت‌ها از `tgju.org` خونده می‌شن؛ اگر موقتاً در دسترس نباشه، آخرین مقادیر از کش نشون داده می‌شه
- والپیپر ویدیویی تا حجم حدود ۴۰MB و عکس تا ۹MB ذخیره می‌شه (محدودیت حافظه اکستنشن)
- آیکون سایت‌های لینک‌ها از سرویس گوگل لود می‌شه؛ بدون اینترنت مربع خالی نشون داده می‌شه
- تنظیمات شیشه (شفافیت / بلور / ثانیه) از دکمه ⚙️ بالای صفحه

## ساختار فایل‌ها

```
chrome-theme/
├── manifest.json      # تعریف اکستنشن (Manifest V3)
├── newtab.html        # صفحه تب جدید
├── css/style.css      # استایل شیشه‌ای + فونت وزیرمتن
├── js/jalali.js       # تبدیل تاریخ شمسی (jalaali-js)
├── js/app.js          # ساعت، لینک‌ها، قیمت‌ها
├── js/wall.js         # والپیپر تصویری/ویدیویی + تنظیمات
├── fonts/             # وزیرمتن (woff2)
└── icons/             # آیکون‌های اکستنشن
```
